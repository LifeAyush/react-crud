# CRUD

An exercise in React CRUD screens for a list, with add, edit, and a dashboard.

The dashboard is the home screen. It shows the list of records and a way to add one. Each record has a name, email, and contact. From the list you can edit or delete a record. Add and edit are separate screens.

## Run

```bash
git clone https://github.com/LifeAyush/react-crud.git
cd react-crud
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).
